🛒 O Boy dos Links
Portal agregador de promoções e cupons de desconto monetizado via links de afiliados. Projeto Integrador do 4º período do curso de ADS - IFRN.

📌 Sobre o Projeto
O O Boy dos Links é uma plataforma web que centraliza ofertas relâmpago, cupons de desconto e links promocionais de e-commerces parceiros (Shopee, Amazon, Mercado Livre, etc.). Ao clicar para obter uma oferta, o usuário é redirecionado através de um link de afiliado do administrador, monetizando a plataforma.

🚀 Funcionalidades Principais
Navegação & Busca: Feed de ofertas recentes, busca por palavra-chave e filtros por categoria.
Cupons de Desconto: Cópia rápida de códigos promocionais ativados com 1 clique.
Redirecionamento Monetizado: Links de afiliados embutidos em todas as ofertas externas.
Painel Administrativo: Gestão completa de promoções, agendamento de ofertas relâmpago e controle de cupons.
